# IRI overnight experiment preparation

Prepare a reproducible comparison of component retrieval methods across models and increasingly complex artificial protein queries. The target is to answer four questions: whether model choice changes recovery, which conditions cause failures, whether local alignment already handles those cases, and where averaging versus sequence context contributes to failure.

This packet prepares the scientific and coordination work. It does not launch experiments, approve downloads, or certify machine readiness. Existing results remain in the experiment repository.

## Files

- `PROTOCOL.md`: experiment definitions, model priorities, metrics, and interpretation.
- `OPERATIONS.md`: delegation, integration, resumability, resource handoff, and launch checklist.
- `LAUNCH_BRIEF.md`: executable instructions and fields to resolve when the session starts.
- `EXTENSION_QUEUE.md`: substantive additional work after the core, starting with automatic segmentation.
- `challenge_manifest.json`: deterministic query design using the existing reviewed proteins, without sequences or inference results.
- `preparation_checks.json`: source checksums, verification, and challenge counts.
- `build_challenge_manifest.py`: reproducible generation of this prepared design.
