# Data: fictional examples only

The `manifests/` and `examples/` folders contain only invented metadata for schema and testing demonstrations. No real accessions, sequences, evidence of biological function, or model outputs are stored here.

T02 documents source selection, benign eligibility, licensing and provenance checks. Only add real public benign records after those checks have been reviewed. Downloaded `.gb`, `.fasta` or related sequence data belong outside Git in ignored local directories. No user/customer/proprietary data are allowed.
